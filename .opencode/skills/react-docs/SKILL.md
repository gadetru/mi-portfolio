name: react-docs
description: Usar cuando se cree o edite código React (componentes, hooks, JSX, estado, efectos) para consultar método de construcción y mejores prácticas en es.react.dev
---

Siempre que la tarea toque React (componente, hook, JSX, props, estado, efectos, formularios, etc.):

1. Identifica el concepto (ej: useEffect, useState, composition, keys, lifting-state).
2. Busca en https://es.react.dev/ con WebFetch/WebSearch, prioriza `es.react.dev/reference/*` y `es.react.dev/learn/*`.
3. Si la página ES no existe o está incompleta, fallback a `react.dev` EN y tradúcelo.
4. Aplica lo encontrado al código y cita la URL usada.

No uses solo tu conocimiento: verifica contra es.react.dev.
No amplíes a otras librerías (Vite, Router) salvo que la página React lo pida.
